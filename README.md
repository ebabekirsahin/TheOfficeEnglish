# The Office English

Learn practical English through *The Office* dialogue transcripts.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data

`data/The_Office_lines.csv` contains the supplied transcript dataset. The app organizes it by season, episode, scene and speaker and provides reading, vocabulary, expressions, phrasal-verb and study tools.

Source: Kaggle – The Office Script Lines.

## Streamlit Cloud

Deploy this repository as a Streamlit app with `app.py` as the entry point.
